# سفرآنلاین | SafarOnline — v4

این بسته شامل پروژهٔ سه اپ اندروید و API مشترک سفرآنلاین است:

- `android/SafarOnlinePassenger` — اپ مسافر
- `android/SafarOnlineDriver` — اپ راننده
- `android/SafarOnlineAdmin` — اپ مدیریت
- `server` — API با Express و SQLite

## امکانات موجود در نسخه دمو

- ورود مسافر و راننده با OTP دمو `123456`
- ورود مدیریت با `admin / 1234567`
- ثبت و مشاهده سفر
- برآورد کرایه
- چرخه سفر: درخواست ← قبول ← رسیدن ← شروع ← پایان
- لغو سفر
- آنلاین/آفلاین شدن راننده
- ارسال موقعیت راننده و جست‌وجوی رانندگان نزدیک
- درآمد راننده
- تأیید/لغو تأیید راننده توسط مدیریت
- آمار مدیریت، مشاهده سفرها و شکایت‌ها
- لوگو و نام نهایی سفرآنلاین در هر سه اپ

## راه‌اندازی API

داخل پوشه `server`:

```bash
npm install
npm start
```

API روی پورت 3000 اجرا می‌شود. تنظیمات نمونه در `.env.example` قرار دارد؛ برنامه فعلی مقادیر پیش‌فرض را نیز دارد.

## ساخت APK

برای Build اندروید به Android SDK و Gradle/Android Studio نیاز است. در محیط فعلی این ابزارها نصب نیستند، بنابراین APK نهایی از داخل این محیط قابل ادعای Build‌شده نیست. پروژه‌های Gradle آماده‌اند و بعد از باز کردن هر پروژه در Android Studio قابل Build هستند.

## آدرس API در اپ‌ها

در صفحه ورود هر اپ، آدرس API قابل تنظیم است. برای شبیه‌ساز Android معمولاً:

`http://10.0.2.2:3000/api`

برای گوشی واقعی باید آدرس IP سیستم اجراکنندهٔ سرور در شبکهٔ محلی استفاده شود.

> این نسخه «دمو/نسخهٔ توسعه» است. OTP ثابت، توکن‌های ساده و نبود سرویس SMS/نقشهٔ واقعی برای محیط تولید مناسب نیست و قبل از انتشار عمومی باید با احراز هویت امن، SMS واقعی، HTTPS، نقشه و Push Notification جایگزین شوند.

## Build واقعی در GitHub Actions

برای عبور از محیط‌هایی که Android SDK/Gradle ندارند، workflow آماده در `.github/workflows/android-build.yml` قرار دارد. این workflow برای هر سه اپ Java 21، Android SDK 35 و Gradle 8.10.2 را فراهم کرده و APK Debug تولید می‌کند. راهنمای فارسی در `BUILD_CLOUD.md` است.
