# میزاری آنلاین — بسته V9

این نسخه یک بسته یکپارچه برای MVP عملیاتی است و شامل سه اپ وب/PWA (مسافر، راننده، مدیریت)، API بک‌اند، Socket.IO، OTP، نقش‌ها، سفر، تطبیق راننده، وضعیت سفر، امتیازدهی، شکایت، داشبورد مدیریت و گردش ساخت اندروید است.

## نکته مهم
این بسته «کد پروژه» و مسیر Build را کامل می‌کند؛ اما سرویس‌های بیرونی مثل SMS واقعی، دامنه/HTTPS، نقشه، Push و پرداخت دیجیتال نیاز به حساب/کلید واقعی خودشان دارند. بدون این موارد، هیچ بسته‌ای نمی‌تواند به‌تنهایی یک سرویس حمل‌ونقل عمومی آنلاین را در اینترنت راه‌اندازی کند.

## تست سریع
در حالت demo می‌توان OTP را با `123456` تست کرد. برای انتشار عمومی حتماً OTP واقعی، JWT_SECRET قوی، HTTPS، CORS محدود و تنظیمات امنیتی تولیدی را فعال کن.

## اندروید
راهنمای گوشی‌محور در `mobile/README-FA.md` و workflowها در `.github/workflows/` هستند.

## ساخت APK آزمایشی با گوشی
برای ساخت سه APK قابل نصب بدون سرور، در GitHub به Actions برو و workflow **Build 3 demo Android APKs** را اجرا کن. این نسخه حالت آزمایشی داخلی دارد و برای ورود از کد `123456` استفاده می‌کند. این APKها برای تست رابط و گردش سفر هستند و هنوز به SMS واقعی، نقشه/سرور عمومی و پرداخت واقعی وصل نیستند.
